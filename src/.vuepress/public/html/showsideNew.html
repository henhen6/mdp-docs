用户中心
用户中心即工作台，是面向全用户的统一业务门户。基于平台 SSO、Oauth2 单点登录能力，为用户提供一站式应用访问入口，集成消息中心、个人中心等功能，支持子系统免密登录与一键跳转。
管理中心
管理中心即控制台，面向平台管理员的后台管控模块。承载组织机构、用户角色、菜单字典等基础数据管理，实现应用、菜单、按钮、数据字段及接口的精细化权限配置与鉴权。统一管理登录日志、操作日志，支撑三方数据同步与系统配置运维，为企业提供安全、可控、高效的中后台管理能力。
开发者中心
开发者中心即开放平台，面向第三方与接入方的能力开放门户。提供子系统接入审批、SDK 下载、接口文档生成查阅服务，支持数据订阅拉取、接口调用管控。通过标准化集成方案，助力外部应用快速接入主数据体系，实现系统间免密互通与能力复用，降低多系统集成成本，构建企业开放应用生态。
前端规范
基于 Vue3、Ant Design Vue 制定统一前端规范，明确编码、命名、目录结构及组件开发标准。规范页面渲染、接口请求、样式编写与 Git 提交规则，配套格式校验机制，保障多团队协作时代码风格统一、可读性与可维护性达标，适配中后台系统高效迭代与扩展需求。
后端规范
基于 Java17、SpringBoot 制定后端编码规范，统一分层架构、接口设计、异常处理及数据操作标准。规范命名、注释、日志与安全校验规则，适配多租户、主数据管理等核心场景，保证代码健壮可扩展，提升服务稳定性与团队协作开发效率。
