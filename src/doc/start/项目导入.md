## 导入后端项目

1. 下载或克隆项目源代码

   请复制以下命令到终端执行。注意：代码存放路径严禁含有中文、空格、特殊字符！

   ```shell
   git clone https://gitee.com/henhen6/mddata.git
   ```

   - gitee： https://gitee.com/henhen6/mddata
   - github：https://github.com/henhen6/mdp
   - gitcode：https://gitcode.com/henhen6/mdp

2. 给项目点一个Star，第一时间知晓项目更新

   ![](/img/doc/mdp-点个star.png)

3. 使用idea打开项目

   ![](/img/doc/mdp-目录结构.png)

4. 点击Maven -> `Show Options Menu` -> `Group Modules` 。目的是：将Maven模块按父子模块展示。

   ![](/img/doc/MavenGroups.png)

5. 点击Maven -> `build Tools Settings` -> `Maven Settings` , 配置实际的Maven路径、Settings.xml 路径、本地仓库路

   ![](/img/doc/MavenSettings.png)

6. 编译项目

   依次编译 mdp-core -> mdp-platform -> mdp-sdk 三个子项目。

   :::: info 提示

   在企业级实战开发时，3个子项目可以独立存在，拆分为3个独立仓库。

   - mdp-core：与业务无关的工具集
   - mdp-platform: 与业务有关的服务和工具
   - mdp-sdk: 提供给第三方调用的sdk接口

   ::::

   1. 使用IDE编译

      ![](/img/doc/mdp-编译项目.png)

   2. 进入3个子项目的根目录，使用命令行编译

   ```shell
   mvn clean install  -Dmaven.javadoc.skip=true -Dgpg.skip=true -Dmaven.source.skip=true -DskipTests=true -f pom.xml
   ```

## 导入前端项目

1. 环境要求

   以package.json中配置为准。

   ![](/img/doc/mdp-vben-package.png)

2. 下载源码

   ```shell
   git clone https://gitee.com/henhen6/mdp-web-vben.git
   ```

3. 安装依赖

   ```shell
   # 进入项目目录
   cd mdp-web-vben
   
   # 使用项目指定的pnpm版本进行依赖安装
   npm i -g corepack
   
   # 安装依赖
   pnpm install
   ```

   :::: warning 注意

   - 项目只支持使用 `pnpm` 进行依赖安装，默认会使用 `corepack` 来安装指定版本的 `pnpm`。:
   - 如果你的网络环境无法访问npm源，你可以设置系统的环境变量`COREPACK_NPM_REGISTRY=https://registry.npmmirror.com`，然后再执行`pnpm install`。
   - 如果你不想使用`corepack`，你需要禁用`corepack`，然后使用你自己的`pnpm`进行安装。

   ::::

4. 运行项目

   - 使用命令: `pnpm dev`

   ![](/img/doc/mpd-vben-本地启动.png)

   - 使用上下键选择项目，按回车启动指定项目

   - 也可以使用如下命令启动指定项目

     ```shell
     # 启动工作台
     pnpm dev:workbench
     # 启动控制台
     pnpm dev:console
     # 启动开发者中心
     pnpm dev:open
     ```
