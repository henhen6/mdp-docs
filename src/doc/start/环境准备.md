## 后端工程

具体版本以[pom.xml](https://gitee.com/henhen6/mddata/blob/master/mdp-parent/pom.xml)定义版本号为准。

- IDEA
- JDK17
- maven 3.5 +
- 数据库： MySql 5.7 / 8.0  或 达梦 或 PostgreSQL
- Redis 6.0+
- Nacos 3.x  

## 前端工程

具体版本以package.json中配置为准。

 ![](/img/doc/mdp-vben-package.png)

- VsCode 或 TRAE CN

- Node: `^22.18.0 || ^24.12.0`

- pnpm: >= 11.0.0（版本以仓库 `package.json` 的 `engines` 与 `packageManager` 字段为准，使用核心包管理器 corepack 可自动对齐）

## 移动端工程（可选）

仅开发移动端（微信小程序）时需要，详见[移动端启动](移动端启动.md)。

- Node: >= 20
- pnpm: >= 9
- 微信开发者工具（最新稳定版）
