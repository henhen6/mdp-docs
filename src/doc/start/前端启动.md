基于vue-vben-admin 5.x版本进行二次开发的系统。该项目是基于 radix-vue、Vue3.x、Vite、 Ant-Design-Vue4.x 、TypeScript、vxe-table 的中后台解决方案，目标是为中大型项目开发,提供现成的开箱解决方案及丰富的示例。

详情的使用文档请参考他们的官方文档：

- vben-admin：https://doc.vben.pro/
- ant-design-vue： https://www.antdv.com/
- vxe-table：https://vxetable.cn/v4/

## 本地运行

1. 安装依赖

   ```shell
   pnpm install
   ```

2. 运行项目

- 使用命令: `pnpm dev`

![](/img/doc/mpd-vben-本地启动.png)

- 使用上下键选择项目，按回车启动指定项目

- 也可以使用如下命令启动指定项目

  ```shell
  # 启动工作台
  pnpm dev:workbench
  # 启动控制台
  pnpm dev:console
  # 启动开发者中心
  pnpm dev:open
  ```


3. 访问项目

   ```shell
   # 访问工作台
   http://localhost:7700/
   # 访问控制台
   http://localhost:7710/
   # 访问开发者中心
   http://localhost:7720/
   ```
