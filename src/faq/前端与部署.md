### 1. 登录报「非法 client」

`VITE_GLOB_APP_KEY` 必须与后端 `sa-token.sso-clients` 中配置的 key **完全一致**：单体版在 `boot-server/application.yml`，微服务版在 Nacos 的 `workbench-server.yml`。

详见：[前端配置](../config/前端配置.md)

### 2. 页面能打开，接口全部 404 / 502

前端模式与后端架构不匹配：`VITE_GLOB_MODE=boot` 必须配单体版（代理指向 boot-server 23455）、`cloud` 必须配微服务版（代理指向 inner-gateway 23450）。

- 启动命令要带模式后缀：`dev:boot` / `dev:cloud`；用了 `dev:workbench` 这类不带后缀的命令实际跑的是 boot 模式，微服务版下表现为"登录正常、部分接口 404"；
- 改完 `.env` 后需重启 dev server。

详见：[前端启动](../doc/start/前端启动.md)

### 3. nginx 部署后页面能打开、接口全 404

仓库自带的 `scripts/deploy/nginx.conf` 只做静态资源托管，**没有 `/api` 反向代理**。生产部署时需自行补充 `location /api` 反代、`proxy_set_header`、超时与跨域配置。

详见：[前端启动](../doc/start/前端启动.md)

### 4. 单点登录的登录页/授权页地址配置后跳转异常

前端路由是 **hash 模式**（`VITE_ROUTER_HISTORY=hash`），后端单点登录配置里的登录页、授权页地址必须带 `/#/`，如 `http://localhost:7700/#/auth/login`。

详见：[前端启动](../doc/start/前端启动.md)

### 5. 控制台点「开发者中心」跳不动

`VITE_GLOB_OPEN_PLATFORM_URL` 指向不对：开发环境为 `http://localhost:7720`；`.env.production` 里是占位域名，**部署前必须改为真实地址**。

详见：[前端启动](../doc/start/前端启动.md)

### 6. 自定义域名访问被拒绝（Invalid Host header）

工作台在 `vite.config.ts` 中显式绑定 `host: 'localhost'`，且 `allowedHosts` 只允许 `127.0.0.1` 与 `localhost`。需要用域名访问时自行把域名加入白名单。

详见：[前端启动](../doc/start/前端启动.md)
